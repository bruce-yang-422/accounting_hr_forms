網站操作說明

本頁說明常用資料、草稿、最近完成，以及表單列印流程。

安裝到主畫面與離線使用

  • 首頁頁尾的「加入主畫面」可啟動支援瀏覽器的安裝流程，或查看安裝方式。iPhone／iPad 可在 Safari 點「分享」→「加入主畫面」。
  • 首次連網開啟後，等待首頁顯示「已可離線使用」，即可離線開啟各表單、常用資料管理及操作說明，並儲存草稿、預覽及匯出 JSON。
  • 資料仍保存在目前裝置與瀏覽器，不會因安裝而跨裝置同步。需要移轉常用名單時，使用 JSON 匯出／匯入。
  • 新版準備完成時可按「立即更新」，目前表單會先暫存，重新載入後還原內容、草稿及預覽狀態；其他分頁不會被強制重載。暫存失敗時會停止更新，保留目前內容。
  • 按「稍後」會記住該版本，不再重複提醒。也可儲存工作後關閉本網站所有分頁及 App 視窗，讓新版自動啟用。
  • 離線功能需使用 HTTPS 網站，或本機 localhost 測試；直接開啟 HTML 檔案不會啟用離線快取。離線時使用裝置可用字型。

首頁快捷功能

點選入口會在下方展開清單，再次點選可收合；切換入口直接更換內容。點清單整列即可開啟表單或續填草稿，星號按鈕獨立控制收藏；按 Esc 或右上角關閉圖示可收合。

  • 最近使用：開啟表單後自動記錄，按「快速開啟」可再次進入。
  • 我的收藏：按表單標題旁的星號即可收藏，實心星號表示已收藏；再次點選或在收藏清單點實心星號即可取消。
  • 未完成草稿：集中顯示各類表單已儲存的草稿，按「繼續填寫」會直接還原指定草稿。未儲存內容不會自動加入。

基本流程

  1. 在首頁依「人事差勤、財務核銷、採購」分類選擇表單；按「全部」可查看十二種表單。
  2. 填寫表單內容，必要欄位會以紅色星號標示。
  3. 手機版頂部保留「下一步」，儲存草稿、草稿庫、最近完成與其他操作收在「更多」。填寫／列印說明及單據編號可按標題展開。
  4. 按「下一步」進入預覽畫面。請假單與請款單可在單據編號旁選擇書店版或完整版；採購申請單可選精簡版（小額採購，A5）或完整版（需比價，A4）。
  5. 確認內容無誤後，按「列印 / 另存 PDF」。
  6. 列印前系統會自動保存一筆最近完成，方便之後載入修改。

公出、零用金、領用與驗收

  • 公出申請單用於同日外出洽公，填寫起訖時間後會計算時數；結束時間須晚於開始時間。多日行程可使用出差申請單。
  • 零用金申請單可選預支或核銷撥付，最多五筆支出，自動加總並轉為中文大寫金額；每筆金額須大於零，最多兩位小數。
  • 物品領用單可記錄領用日期、倉庫、保管人與最多五筆物品；每筆須填名稱、單位及大於零的數量。
  • 採購驗收單記錄採購單號、供應商、驗收日期及訂購／實收／合格數量；合格數量不可超過實收，數量差異或不合格須填寫異常與處理說明。
  • 四種表單均支援草稿、範本、最近完成、自訂簽核、空白單列印及 A5 橫向 PDF。審核方式與既有表單一致：在列印預覽底部提供主管同意／退回勾選、各單位確認填寫線及簽名蓋章欄，列印後交由相關人員填寫；名稱與項目可至「常用資料管理 → 簽核設定」調整。驗收範本保留品項與訂購數量，實收、合格數量及驗收結果須每次重新填寫。

常用資料

常用資料用來保存常用填表人資訊，避免每次重複輸入。

  • 可保存姓名、單位、職稱、請假及出差代理人、個人連絡電話。
  • 「常用資料管理」分頁可新增、編輯、刪除常用資料，並設定預設資料。
  • 進入表單時，預設常用資料會自動帶入可對應欄位。
  • 表單姓名欄旁的「常用資料」按鈕，可手動選擇其他常用資料帶入。
  • 管理頁分成「個人資料」「付款對象」「備份移轉」三個頁籤，清單預設每頁 20 筆，也可切換為 50 筆；搜尋涵蓋全部資料，並支援單位、身分及付款方式篩選。
  • 按「新增」或「編輯」開啟獨立視窗，未儲存就關閉時會提醒。完整聯絡資訊與銀行資料可按「查看」展開。
  • 表單內的個人及付款對象名單使用可搜尋的選擇視窗，按「帶入」即可填入；既有個人資料與付款名單仍可繼續使用。

常用資料 JSON 匯出／匯入

「常用資料管理」分頁的「付款對象與付款方式」可搜尋、新增、編輯及刪除請款對象，維護戶名、受款方身分、付款方式、統編／身分證字號與銀行帳號。請款單提供直接管理入口，名單與 JSON 備份共用資料。

「常用資料管理」分頁的「簽核設定」可調整各表單列印時的簽核欄與審核區，每張表單各最多 6 項。留空不列印，審核區全部留空時整區不印；審核項目可印填寫線或勾選項目，也可恢復預設。採購單的精簡版與完整版分開設定。

到常用資料管理的匯出／匯入區塊，可將個人常用資料、請款對象名單、各表單範本及簽核設定一起備份。

  • 按「匯出全部常用資料」下載 JSON，包含預設人員、代理人、電話及付款對象的銀行資料。
  • 匯入前選擇備份檔，系統會檢查格式並顯示各類別筆數；確認後才儲存。
  • 合併模式：個人以姓名＋單位、付款對象以戶名、範本以同類表單的範本名稱判斷重複，同名保留現有內容及目前預設人員。
  • 取代模式：覆寫檔案包含的類別，空名單也會清空該類別；未包含的類別保留。
  • 備份不包含草稿、最近完成及內建請假理由範本。移轉到其他瀏覽器後可匯入使用；已開啟的表單需重新整理。

範本庫

每種表單各可儲存 20 筆範本，與草稿、最近完成共用同一個資料庫視窗；每頁顯示 5 筆，可搜尋全部內容。

  • 先填寫固定內容，按「範本庫 → 將目前表單存為範本」，輸入好辨識的名稱。
  • 按「套用」並確認，會保留目前申請人，申請日期改為今天；舊單號、憑證號碼、憑證日期及請假、加班、出差、需求等日期會清空，避免沿用舊資料。
  • 請款範本保留科目、金額、付款資料及備註；請假範本保留假別、理由、時段與固定說明；加班範本保留日別、時段與事由；出差範本保留地點、交通與預估費用；採購範本保留品項、供應商與用途。
  • 按「管理範本 → 修改內容」後，在原表單修改，完成後按「儲存範本變更」。也可重新命名、刪除，或透過 JSON 備份移轉。

草稿

草稿適合保存尚未完成、暫時不列印的表單。

  • 每種表單各自最多保存 20 筆草稿。
  • 按「儲存草稿」可命名，選擇更新目前草稿或另存新草稿；表單會顯示目前草稿與未儲存變更狀態。
  • 按「草稿庫」可搜尋、排序、查看內容、載入、重新命名及刪除；載入前會要求確認，避免取代尚未儲存內容。
  • 草稿達上限時，可進入草稿庫刪除舊草稿，再返回儲存流程；仍可更新目前草稿。刪除草稿會保留目前表單內容。

最近完成

最近完成用來保存已準備列印或另存 PDF 的表單。

  • 按「列印 / 另存 PDF」前會自動保存。
  • 每種表單各自最多保存 20 筆最近完成。
  • 超過 20 筆時，系統會自動移除最舊紀錄。
  • 按「最近完成」可搜尋、分頁查看與刪除；「載入修改」保留原始內容，「另開新單」清除日期與單號後帶入固定內容。

資料保存限制

本網站是純靜態前端工具，資料保存在瀏覽器的 localStorage。

資料只存在同一台裝置與同一個瀏覽器。清除瀏覽器資料、使用無痕模式、換電腦或換瀏覽器，都可能導致資料無法讀取。
